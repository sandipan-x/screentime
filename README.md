# ScreenTime

Kids screen time guidelines by age: daily limits, a family media plan builder, device curfew, and a weekly report card. Free tool.

## Features
- Age-based daily screen time limits aligned with pediatric guidance
- Family media plan builder with earn-extra-time chore links
- Device curfew calculator plus a weekly report card
